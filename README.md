# 🌱 AI 나뭇잎 분류 & 윤리 시뮬레이터 (Streamlit 웹앱)

## 1. 실행 방법
터미널(또는 Anaconda Prompt)에서 압축을 푼 폴더로 이동한 뒤 아래 명령어를 순서대로 입력하세요.

```bash
pip install -r requirements.txt
streamlit run run.py
```

## 2. 기본 계정 정보 (기존 myproject.db 연동)
- 아이디: `taehuie` / 비밀번호: `taehui`
- 또는 메인 화면 [신규등록] 탭에서 새 계정을 만들어 로그인할 수 있습니다.

## 3. 메뉴 구성
- **1. 데이터 입력 및 DB 구축**: 첨부된 `나뭇잎 데이터.xlsx`를 정제한 기본 데이터셋(은행, 단풍, 벚나무, 감나무, 밤나무, 화살나무 각 30개씩 총 180개)이 기본 세팅되어 있으며, 단일 추가 및 CSV 일괄 업로드/다운로드가 가능합니다.
- **2. 3D 산점도 및 이상치 검증**: 가로(X), 세로(Y), 잎자루(Z) 3D 산점도를 회전하며 관찰하고, `🚨 조작된 가짜 데이터 3개 투입` 버튼을 눌러 정상 군집에서 벗어난 이상치를 직접 찾아 삭제하는 활동을 진행합니다.
- **3. AI 자동 분류 시뮬레이터**: KNN 및 SVM 모델로 식물 종을 자동 분류하고, 가짜 데이터 오염 여부에 따른 모델 정확도와 예측 신뢰도 변화를 비교합니다.
- **4. AI 윤리 실태조사**: 10문항 자기점검 결과를 SQLite DB(`myproject.db`)에 저장하고 조회합니다.
